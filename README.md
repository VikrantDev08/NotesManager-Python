# NotesManager-Python
A Basic Notes Program made in Python that can save and retrieve data locally on your PC

Prerequisites - 
**Python 3.X** installed on your computer

Features - 
1. Save Files Locally on your PC.
2. Access your data anytime without internet access.
3. Lightweight and easy to run from the command line.

Working -
The Program Uses CSV and Text files to store user data and Text locally and securely on your PC.
